# 学生视角的部门与栏目复核（2026-09-24）

学生相关信息优先展示和调查，其他信息继续保留、可查看、可订阅。排序不改变学校机构归属，不改写用户的订阅范围，不因官网撤下通知而删除历史记录。

## 本次结果

检查了本机登记的 6 所学校的来源配置与已发布目录。详细官网复核和数据修正集中在上海交通大学：原有 34 个来源没有形成学院栏目层级，并存在把 Read、了解按钮识别为栏目，以及研究生院两个不同栏目使用同一段列表的问题。

依据[交大官网院系设置](https://www.sjtu.edu.cn/yxsz/)、学院网站及实际通知列表，修正原有 34 个来源，新增 86 个栏目，共 120 个来源；其中 24 个学院已有可确认并接入的栏目。学院优先，其次招生、教务、研究生事务；新闻、科研、行政、教师发展信息继续提供。

已接入的例子：

- 电气工程学院：本科生通知、招生工作，含推免名单及考核办法。
- 药学院：人才培养下的招生工作、学生园地通知，含推免、夏令营、奖学金信息。
- 机械与动力工程学院：分别保留本科生教学网和研究生教学网的通知入口。
- 设计学院：招生资讯、学院公告，包含推免公告。
- 研究生招生网：硕士、博士、港澳台招生等；教务处：面向学生的通知。

利用本次保存的有效列表页增量录入 559 条新通知；本次应用时交大共有 774 条通知。后续正常采集会继续增加数量。更新前全库 7,028 条通知的完整记录逐条比对未变，原有 304 个来源 ID 全部保留，账号、订阅、已读及个人状态表的摘要一致。跨栏目相同原文使用数据库唯一身份去重，并保留来源关系。

## 可复用的修正

- 明确请求的就绪条件没有出现时，静态新闻不能代替目录导航；交大脚本生成的院系导航通过统一抓取入口渲染后读取。
- 院系官网的页面标题、校名、官方目录、实际跳转和栏目链接共同提供归属证据。学院链接到研究生院只记录导航关系，不据此宣称研究生院的通知属于该学院。
- 追踪已核实学院内部的本科、研究生、招生入口，保留中间导航上下文；登录按钮不进入栏目名称。
- Read、了解等动作按钮不能替代标题。日期分行和摘要卡片使用独立标题、日期元素；页面主题类名 header-white 不得把整页误判成导航。
- 目录发布保留全部已观察栏目，学生优先只影响调查顺序和展示排序。

## 应用和恢复

`scripts/apply_source_review.py` 默认只预览。带 `--apply` 才写入；每条修正绑定学校、原来源 ID、完整旧配置、网页文件及 SHA-256。网页证据或旧配置改变即拒绝覆盖，重复执行不会新增相同 URL 与选择器的来源。脚本不删除来源、不改订阅。

本次清单、网页证据、预览和结果在 `data/source-audits/student-review-20260924/`。运行目录以新批次发布，主库激活该批次。变更前一致备份为 `data/school_watcher.db.backup-student-review-20260924-205112`。恢复主库前须停止网页和 worker，并同时保留相应的目录版本文件；不要用普通通知导出替代完整备份。

## 验证与边界

自动化测试覆盖就绪判断、目录归属、跨站旁链、学生排序、栏目标题与日期、审核清单幂等及历史记录保留。全套 519 项测试中 498 项通过、21 项因相应浏览器或 PostgreSQL 环境未启用跳过；本次另用本机 Edge 完成隔离目录的桌面和手机预览。

这不是全部学校已经核实的声明。交大官网目录包含 69 个学院/机构条目，本次并未接通全部条目的全部栏目；官网指向目录自身的新学院入口、无法访问的页面、无法区分标题的多个组件、缺少可靠列表证据的页面继续待核实。研究机构和非学生信息仍保留在目录中，不以学生优先为理由剔除。现有同名但不同 URL 的历史来源未强行合并，避免破坏既有订阅。

另外 5 所学校本次完成配置层检查，尚未完成同等深度的官网逐栏复核。`registered-schools-before.json` 中的 `officially_placed` 只是路径投影统计，不包含显式目录成员关系，不可当作正确率或覆盖率。
