# 电子科技大学通知采集核对（2026-09-21）

官网“教学科研单位、研究机构”中的 43 个目录条目仍保留。目录可选择不代表通知已采集成功。本次核对结果：

- 信息与通信工程学院已保存 31 条；广东电子信息工程研究院本次补入 18 条。
- 39 个单位最近一次采集返回访问校验、HTTP 403 或 HTTP 412；其中医学院按用户要求已取消订阅，不再自动采集。旧失败记录保留。
- 电子薄膜与集成器件全国重点实验室返回动态页面外壳；其公开脚本中实际使用的通知接口连接超时，仍待适配。
- 电子信息智能研究院的目录条目没有官网链接。

不能据上述响应断言是并发过高、海外出口或反爬识别造成的。对电子科学与工程学院、材料与能源学院和医学院使用浏览器验证，观察到校验脚本加载后返回空白错误页面；医学院另用带界面的浏览器验证，结果相同。未部署自动破解或全校浏览器重试，也未修改用户的 Clash 网络设置。

广东研究院漏抓源于通知列表交替使用两种装饰类。新增针对该 MetInfo 列表结构的解析规则，保持原日期、栏目标题及原文链接；标题与面包屑冲突时不猜测分类。第一次实际采集新增 18 条，第二次检查仍为 18 条、新增 0 条；第二次有一个附带页面读取失败，因此日志标为部分完成。这批列表最新日期为 2025-04-28，在“全部时间”中查看，不属于近一周新通知。

侧栏现在区分待采集、等待更新、更新中、访问受限、访问异常和待适配。没有取得通知时显示数量未知，已有消息数量继续保留。完整页面、局部筛选和采集进度轮询使用相同状态，不因请求失败显示为成功的空列表。医学院仅从当前订阅中移除，单位目录、编号和历史记录仍在，可重新订阅；其余来源采集范围不变。

342 项单元/API 测试通过，桌面和手机浏览器验证覆盖状态实时更新、局部刷新、增量去重和失败时保留已有消息。修订访问拒绝提示后另通过 4 项抓取失败测试。完整 43 项通知来源尚未接通。

详细结果见 `data/source-audits/uestc-collection-status.json`；浏览器响应证据见 `uestc-browser-diagnosis.json`、`uestc-headed-browser-diagnosis.json`；医学院订阅变更前后记录见 `uestc-medical-unsubscribe.json`，均位于同一审计目录。
