# 轻量高校信息订阅改进

需求基准：轻量网站，订阅中国一本及以上高校官网信息，分类尽量贴近**学校自己的栏目**。不使用个人偏好学习来改写官方分类。

## 实现

当前采用网站与采集分离的单机试运营结构，详见[部署、迁移与最新验收记录](DEPLOYMENT.md)。下方 2026-09-19 验证记录是历史记录，不代表当前数据库数量或最新调度方式。

- 内置 200 所高校目录，147 所双一流成员按 2022 年名单标记，53 所为补充本科高校；支持简称、地区、订阅状态筛选与手动添加学校。目录本身不写库或触发采集。
- 栏目订阅使用 subscriptions.department_ids，NULL 表示全部栏目；数组表示用户明确选择的栏目。保存时验证栏目属于对应学校。订阅涉及的栏目并集决定后台抓取范围。
- 收件箱支持按学校、分组、学院选项进行局部增量刷新；浏览器整页刷新和“刷新全部订阅”更新当前用户全部订阅来源，保留现有筛选。网页只提交任务，采集仍由独立进程执行。每个来源使用共享任务编号，60 秒内的重复刷新复用结果或正在执行的任务；单个用户每分钟最多提交 30 次。
- 学校更新和每日健康检查拆分成单来源任务，默认两路并发，避免一所学校的长任务占住采集进程。新学院采集首先检查其官网主页和最多两个站内发布栏目，不下载正文、不全站调查；每条文章仍按原文链接去重，学院编号保持不变。访问校验页和未识别的栏目显示失败原因，不能按“零条新消息”报告成功。
- 系统管理新增按学校查看的抓取记录：近七天自动完整加载，更早记录默认折叠、展开后分批读取。记录保留时长可选 7/30/90/180/365 天或永久，默认 30 天，每日维护应用最新规则；不删除通知或用户收藏。
- 官网分组与栏目名称贯通 YAML 导入、发现、收件箱、订阅管理和阅读详情。缺失分组显示「其他栏目」。官网首页栏目不再被导航隐藏，临时为空的栏目不再由后台自动删除。
- 收藏与归档放入 user_announcement_states，已读仍使用原有 user_reads。收藏、归档不改动公告源数据；退订保留收藏和归档。已下架来源在收件箱和收藏视图中隐藏。
- 收件箱查询与批量已读复用同一过滤服务，支持学校、官网分组、栏目、关键词、时间、已读状态和收藏/归档范围；批量写入仅影响当前用户。
- 未选中通知时不自动加载正文或标记已读。阅读和收藏时通过持久任务补取正文，第二页点击通知保留页码；标题、摘要和已保存正文可搜索。
- 基础安装不要求 OpenAI SDK、Playwright、Scrapling 或 curl_cffi。默认静态请求、每栏目每轮 3 页；独立采集进程最多执行两个任务，官网请求总并发为二。已订阅来源每日检查，目录每月检查；适配任务每轮最多 20 页、深度四层、每校最多 1,000 个页面记录，可中断恢复。
- 精简目录保留 201 所学校的既有调查成果和核验关系；临时调查缓存与运行目录分开。未收藏正文按 150MB／30 天淘汰，调查缓存按 100MB／7 天限制，收藏及个人记录保留。
- 新增公开 URL 验证，拒绝内网地址、非 HTTP 协议和转向内网的 HTTP 重定向；补充栏目限同一高校域名。
- 列表探测使用已有的评分检测器，移除全页 a[href] 回退。补充带标题、时间和博达文章地址的图文列表模式，过滤英文版切换等导航标题。
- 删除无人调用的 Selenium 抓取实现、重复设置与学校管理模板，以及仅凭条数删除来源的旧清理函数。旧设置地址跳转到统一后台，旧启动器转调统一启动脚本，安装和快捷方式脚本不再绑定开发机路径。
- 单校页面精简为公开信息预览；已订阅用户统一进入收件箱。移除旧的 DAILY NEWS 虚拟分类、按名称猜测分类与重复阅读操作，近七天改用收件箱时间筛选；存量来源和公告记录保留。

- 旧版本数据库迁移验证：现有通知、来源分组、订阅及已读状态保留；迁移后数据库与模型定义一致。
- 用户数据库已备份并升级：升级前后均为 3 所已入库学校、194 个来源、5,474 条公告、5 条订阅和 2,962 条已读记录，SQLite 完整性检查通过。未向用户数据库写入界面或采集测试数据。
- 关闭全部可选包的导入检查：基础应用、学校目录、静态发现和无 Key 的摘要跳过行为可用。
- 当前 Python 3.14 环境使用 PyYAML 6.0.3 并通过上述运行检查；基础依赖不再固定到旧的 6.0.2。新版提供相应的 Windows 安装包，见 [PyPI 发布文件](https://pypi.org/project/PyYAML/6.0.3/#files)。

- 23 项轻量功能回归与 5 项原有界面回归通过；精简单校预览及旧设置入口跳转已覆盖，浏览器未报告 JavaScript 异常。使用实际数据库启动后，目录、登录、单校预览与新增样式请求均返回成功。
- 官网实测：清华大学、北京大学首页可静态获取并发现栏目；清华新闻列表成功提取正式文章标题、原文地址及 1,537 字正文，写入隔离内存数据库验证，未污染用户数据库。
- 克拉玛依校区官网在本机解析含私有 IPv4 地址。后续已验证公开 DNS 返回公网地址，并通过固定公网连接、保留原域名 TLS 验证取得官方页面；未放行私有地址。详见来源完整性记录。
- Impeccable 检查器因缺少 HTML 解析模块退化为文本规则检查，未报告问题；这不等于完成自动化对比度审计，另有真实浏览器与截图检查。

## 边界

这是官网入口目录与可扩展的公开网页采集器，不是已经逐校验收的全国所有栏目覆盖清单。其他本科高校集合不是完整全国一本名单。没有新增持续付费 AI 服务、消息推送服务或公网部署。

静态模式不处理校内登录与部分依赖浏览器的网页。学校改版时仍可能需要重新选择栏目或由管理员维护选择器。没有全量重抓历史数据，也没有自动删除存量数据库中的旧噪声记录。
