# 官网目录与订阅来源的展示

收件箱以官网目录中的父子路径显示单位，再显示该单位已接入的栏目。`Department.group_name` 是旧的采集来源元数据，可能保存的是单位名，不能单独作为官网目录的顶级分类。

## 关系来源

- 已保存的 `DepartmentDirectoryEntry` 优先，支持多父级和嵌套目录。
- 缺失的祖先从精简运行目录的 `official_website_entry` 路径恢复；网页请求只读本地目录，不执行调查或抓取。
- 排除学校首页的旁链、专业与机构的混淆、同表并列标题造成的伪层级。没有充分依据的旧入口继续保留，不单凭同名合并。
- 旧的明确“单位-栏目”关系作为回退；祖先可以参与展示，但不会把未订阅的兄弟栏目加入用户范围。

`source_hierarchy()` 的每个节点用 `own_columns` 保存本级栏目，用 `children` 保存子单位，用去重后的 `columns` 提供完整后代范围。收件箱筛选、刷新当前范围和扁平选择器复用该投影。显示键包含完整路径，保证同一来源在多处列示时收展独立、勾选同步。

本次不迁移数据库，不变更来源及通知编号，不改变任何用户订阅。请求内缓存每校运行目录，避免同一次筛选重复解压；不读取旧调查库，不引入前端依赖。

## 验证范围

2026-09-22 检查当前配置的 5 所学校、270 个来源。依据充分的例子包括克拉玛依校区“院系设置 → 地球科学与工程学院 → 通知公告／院内新闻”和北京校本部海南研究院的院系目录位置。未获得完整证据的来源保留回退显示；此次不代表全部目标学校目录已核实。

- `tests/test_source_placements.py`：官方路径、旁链排除、缺证回退、学校隔离、请求缓存。
- `tests/test_inbox_navigation.py`：多层结构、多归属、未订阅来源隔离、未知旧入口、目录嵌套。
- `tests/test_inbox_refresh.py`：分类筛选与采集范围一致，保持账户隔离。
- `tests/check_source_hierarchy_browser.py`：桌面和手机收展、选中同步、父级全选、滚动保持、历史返回、唯一 DOM 标识；`--real-cupk` 将公开目录元数据复制到临时数据库以核验实际路径。

审计结果在 `data/source-audits/hierarchy-review-20260922.json`，界面验收结果在 `data/ui-check/source-hierarchy-browser-report.json`。真实目录截图采用隔离预览库，其中的通知数量与待采集状态不代表运行网站。
