Windows 和 macOS 桌面版：打开即用，精简安装包，无需安装 Python。

此版本修复安装版首次订阅时栏目发现无法启动的问题，补齐解析器版本信息与 AI 规则资源。

首次订阅直接使用 AI 辅助识别；未配置时提供配置入口，保存目录识别用途后自动继续。订阅页实时显示检查页数、当前步骤和失败状态，支持重试。已有的正文清洗、请求安全及账户会话修复继续保留。

- Windows x64：下载 `windows-x64-setup.exe` 安装；也提供便携 ZIP。
- Apple 芯片 Mac：下载 `macos-arm64.dmg`。
- Intel Mac：下载 `macos-x64.dmg`。macOS 构建目标为 macOS 15 及以上。
- 应用菜单提供“检查更新”，从正式 GitHub Release 下载匹配的安装包，校验 SHA-256 后由用户确认安装。
- 无需注册或登录，直接管理学校、栏目、采集和 AI 设置。升级时保留原有订阅、收藏和阅读记录。
- 优先使用电脑已有的 Edge／Chrome；缺少可用浏览器时，从官方源下载独立 Chromium 到用户数据目录。首次下载需联网，可查看进度并重试。支持动态网页和人工验证。
- 全新安装的学校列表为空，从学校目录选择自己的学校后开始接入。安装包不再携带开发阶段选定的学校预设。升级隐藏未使用的旧预设，保留用户已订阅和已有通知的学校。
- Windows 安装向导使用简体中文，修正快捷方式选项边距；主窗口移除重复标题和菜单栏，更新入口移至右上角应用菜单。
- 成功提示自动收起；可设置抓取起始发布年月，历史列表分批续抓并显示页数，修复三页上限导致的漏抓及旧版错误增量判断。
- 缩短发现批次的等待，复用刚完成的采集检查，减少重复请求。
- 用户数据独立存储，更新和卸载不会删除订阅及阅读记录。退出应用后停止本机采集和组件下载。

AI 服务需自行配置。官网可能需要人工访问验证；识别出的栏目仍须通过网页和归属检查后接入。

本版本暂未配置 Windows 商业代码签名和 Apple Developer ID 公证，系统可能要求确认开发者来源。请核对仓库和校验文件。macOS 安装方式为打开 DMG，将应用拖入 Applications。

仓库公开后，普通用户才能无需授权地检查和下载更新；私有仓库阶段仅用于开发验证。安装包不含开发者的本机数据、凭据或宣传片材料。
