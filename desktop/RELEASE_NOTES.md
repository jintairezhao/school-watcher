Windows 和 macOS 桌面版，本次改善窗口、文件位置与存储管理。

- Windows 最大化使用当前显示器的可用区域，保留任务栏；标题、导航与窗口按钮合并为一条应用栏。
- Windows 安装时可选择程序、个人数据、缓存、备份及更新包的位置。安装后在「存储管理 → 文件位置」更改；迁移会校验数据库和文件，保留原目录副本并重启。
- 更改程序位置会下载并校验正式安装包，通过安装向导重新安装；macOS 使用 DMG 与 Finder 移动应用。
- 存储类别后直接提供清理按钮；保留天数、缓存容量与备份份数由用户设置，0 表示不限制。
- Windows 卸载默认保留个人数据，也可主动选择删除当前应用的数据、缓存和自动备份。自定义目录中的其他文件、手动导出的备份与迁移前副本保留。

全新安装不含开发者的订阅、通知、凭据或宣传片资料。升级保留已有数据。安装包仍优先使用系统 Edge／Chrome，缺少时单独下载采集组件。

Windows x64 下载 setup.exe，或使用便携 ZIP；Apple 芯片与 Intel Mac 分别下载对应 DMG，macOS 15 及以上。应用菜单可检查 GitHub 正式版本更新，校验 SHA-256 后确认安装。

本版本未配置 Windows 商业代码签名或 Apple Developer ID 公证。仓库公开后，普通用户才能无需授权地检查和下载安装包。
