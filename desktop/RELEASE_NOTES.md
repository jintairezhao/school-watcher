School Watcher 2.1：从学生的信息需求出发重建学校栏目发现，支持手动检查官网变化，减少重复 AI 调用。

- 首次订阅自动沿学校目录、院系与机构、信息发布栏目逐层发现，覆盖学院和行政部门。通知、公告、公示类栏目默认完整接收，不因通知已截止而舍弃历史参考信息。
- 后续不再定期重跑整所学校。遇到官网改版、栏目缺失或更新异常时，可在“栏目订阅”点击“检查官网变化”：轻量核对已知入口，只对新增、变化或异常部分继续深入识别。
- 保存可复用的结构记录，区分新通知与网页结构变化。清理临时缓存后仍可比较已有记录；同一轮检查分段续跑，不重复打开已检查的入口。
- 栏目规则修复和已确认的官网跳转尽量沿用原栏目，保留订阅选择与历史通知。结构记录缺失的旧页面会先建立记录，无法确认的新旧栏目对应关系不会被强行合并。
- 普通阅读和日常同步不自动分析每篇通知。正文提供“分析用途与时间”按钮，按需分析学生用途、时间和历史参考价值，相同正文复用已有结果；往年安排不代表今年安排。
- AI 主要辅助用途不明的入口和常规解析无法处理的栏目，材料分块并保留进度。每校每轮发现默认最多使用 200,000 Token，可在用量设置调整；本轮子任务和续跑共享额度，到限后保留未完成入口。
- 改善部门待接入提示、检查进度和阅读页信封交互，刷新栏目进度继续保留未保存的订阅选择。

升级保留已有订阅、通知、收藏与阅读记录。源码与安装版默认使用同一桌面数据位置；旧源码项目的 `data/` 不会自动移动，可用 `python app.py --data-dir "原数据目录"` 继续使用。应用继续采用无需账号的本机桌面模式。

Windows x64 提供安装程序和便携 ZIP；Apple 芯片与 Intel Mac 分别提供 DMG，macOS 15 及以上。首次启动优先使用 Edge／Chrome，缺少时下载独立采集组件。安装包不含开发者数据和凭据。

部门目录样本与自动化测试通过不代表所有学校栏目都已覆盖。AI 服务需自行配置；本版未配置 Windows 商业代码签名或 Apple Developer ID 公证。

旧版本若提示不支持两段式版本号，请从本 Release 手动下载安装；2.1 已支持两段式与三段式版本比较。
