本次修复桌面版卸载残留进程，以及抓取过程中更改文件位置的迁移与恢复。

- Windows 应用右上角「…」菜单新增「卸载学校通知」，退出后台服务后打开卸载向导，可选择保留或删除个人数据。
- 卸载前清理同一安装位置启动的后台进程；应用意外关闭时，也会结束它创建的服务和采集浏览器，减少文件占用。
- 更改数据、缓存、备份或更新包位置时，先暂停抓取并保存进度，确认后台退出后再复制和校验，成功重启后继续未完成的任务。
- 迁移窗口显示保存进度、关闭服务、迁移校验等阶段；等待保存时可取消。等待超时或复制失败时保留原数据和原位置设置。
- 导入、导出、更新下载或采集组件准备期间，避免并发迁移；修复 Windows 状态文件短暂占用导致的迁移错误。

升级保留已有订阅、通知、收藏与阅读记录。全新安装不含开发者的个人数据或宣传片资料。

Windows x64 下载 setup.exe，或使用便携 ZIP；Apple 芯片与 Intel Mac 分别下载对应 DMG，macOS 15 及以上。0.1.1 用户可通过应用菜单检查更新。仍使用早期误编号 0.2.x 的用户，请手动下载并覆盖安装一次，之后继续按 0.1.x 检查更新。

本版本未配置 Windows 商业代码签名或 Apple Developer ID 公证。私有仓库阶段，下载与检查更新仍受仓库访问权限限制。
