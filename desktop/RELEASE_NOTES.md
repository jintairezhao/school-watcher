School Watcher 2.5：自动查找学生信息，按真实发布渠道整理通知。

- 关注高校后自动查找公开通知，已找到的消息立即可读，不再要求用户先核实部门归属或逐个选择栏目。需要缩小接收范围时，仍可自行选择来源。
- 优先探索通知和学生常用入口；AI 根据官网已有证据辅助选择路径、识别特殊列表，并以少量标题样本说明信息对学生可能有什么帮助。标题判断明确标注依据，不推断个人资格，不隐藏低相关或尚未判断的通知。
- 发现工作分批执行、保存进度，AI 使用小批量材料和缓存，遵循既有额度及关闭偏好。失败页面限频恢复；官网改版后重新识别并实际验证读取规则，保留已有通知和订阅。
- 新增“按发布渠道”：按学校、实际发布单位或官网站点、栏目归集通知，查看通知数、未读数和全部历史。每条消息可直接跳到对应渠道；多渠道刊载保留各自原文链接，同名栏目按真实来源区分。
- 无法确认发布单位时保留实际官网地址及栏目路径，不猜测归属，也不把刊载渠道冒充原创作者。来源整理及渠道浏览不新增 AI 调用。
- 修复栏目位于目录分类下时部分页面无法打开、学校及来源删除失败、已删除来源继续写入，以及部门数量较多时阻塞首批通知接入等问题。
- 改进常见表格列表、独立日期、附件及图片正文通知的读取；单个置顶消息无法读取时，会在有限样本内继续验证该栏目。
- 删除操作使用应用内确认弹窗，支持深浅外观与失败重试。修复打开来源侧栏时的窗口控制、拖动及 Windows 任务栏最小化行为。

升级保留已有订阅、通知、收藏与阅读记录。源码与安装版默认使用同一桌面数据位置；旧源码项目的 data/ 不会自动移动，可用 python app.py --data-dir "原数据目录" 继续使用。应用继续采用无需账号的本机桌面模式。

Windows x64 提供安装程序和便携 ZIP；Apple 芯片与 Intel Mac 分别提供 DMG，macOS 15 及以上。首次启动优先使用 Edge／Chrome，缺少时下载独立采集组件。安装包不含开发者数据和凭据。

验证码、访问拒绝或尚不支持的动态页面仍可能暂时无法读取，已有消息继续保留。AI 服务需自行配置；标题用途提示不能替代官网正文。未配置 Windows 商业代码签名或 Apple Developer ID 公证，系统可能显示未签名提示。

版本号沿用两段式编号。旧版本若提示版本号格式不受支持，请手动下载安装包；更新比较继续兼容旧版本。
