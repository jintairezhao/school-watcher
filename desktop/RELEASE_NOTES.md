School Watcher 2.25：独立桌面窗口与 API 用量页面的语言修复。

- 更新检查、采集组件、文件迁移和启动窗口使用与应用相同的语言设置与翻译。切换语言后，已打开的更新窗口及其标题同步切换；记住下次启动时使用的语言。
- 补齐更新状态、下载进度、错误提示与安装确认的英文。
- 修复 API 用量中“栏目发现”“连接测试”等动态分类未翻译的问题。语言切换与刷新不改变已记录的 Token、调用次数或历史数据。
- 将旧摘要用量标为“历史摘要调用”，移除设置中仍暗示可生成摘要的说明。阅读页不恢复摘要生成入口，历史账目与旧兼容接口保留。
- 增加独立桌面页面的翻译检查、34 个窗口状态检查，以及含真实格式历史记录的中英文用量页面检查。隔离验证不调用付费 AI。

English: Native update, collection-component, migration, and startup windows now share the application's language catalog. Open update dialogs and their titles follow language changes, including update errors and installation confirmations. API usage categories are localized, and old summary usage is clearly labeled “Historical summary calls.” Recorded usage is preserved; this release does not restore the reader's summary-generation entry. Legacy authenticated interfaces remain available for compatibility.
