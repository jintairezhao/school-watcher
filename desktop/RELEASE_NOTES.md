本次合并学校发现、桌面更新和 API 用量统计的改进。

- 学校目录支持输入即时匹配、清空搜索与筛选联动，兼容中文输入法。
- 每次启动后台检查新版本，发现更新后提醒；用户确认后才下载和安装。
- 修复 Mac 页面安全策略与原生接口的兼容问题，恢复页面中的更新提醒和文件位置操作，保留动态脚本执行限制。
- Windows 应用内更新沿用已有程序、数据、缓存和备份位置，退出后台服务后完成升级，不再重复填写安装向导。首次安装与主动更改位置仍保留设置步骤。
- 新增独立「API 用量」页面，展示调用次数、已知 Token 用量、年度活动、每日趋势、模型与用途分布，以及预算占用；可切换近 7、30、90 天。
- 栏目发现新增「暂停 / 继续」，保存已检查页面和 AI 结果；当前页面处理完成后暂停，重启后仍保持暂停状态。
- 修复部分 WordPress 官网把文章误认为栏目的问题，按官网分类链接归入对应栏目；升级后自动重新检查符合条件的旧待核实记录。
- 修复网页换行导致证据校验失败的问题，改进受限页面、AI 识别失败和来源核实的提示，并优化 AI 服务配置表单。

升级保留已有订阅、通知、收藏与阅读记录。全新安装不含开发者的个人数据或宣传片资料。

Windows x64 下载 setup.exe，或使用便携 ZIP；Apple 芯片与 Intel Mac 分别下载对应 DMG，macOS 15 及以上。旧版用户首次升级到本版时，仍可能看到旧版发起的安装界面；安装本版后，后续 Windows 应用内更新使用简化流程。Mac 更新仍需打开 DMG 完成替换。仍使用早期误编号 0.2.x 的用户，请手动下载并覆盖安装一次。

本版本未配置 Windows 商业代码签名或 Apple Developer ID 公证。
