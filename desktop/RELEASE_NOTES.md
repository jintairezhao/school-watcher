School Watcher 0.2.0：源码与安装包统一为无需账号的本机桌面应用，重做学校接入与部门订阅。

- 移除网页登录、注册、密码找回、个人中心、用户管理及相关 API。源码执行 `python app.py` 或 `scripts/run.bat` 即打开同一桌面程序；保留本机访问凭据和写操作保护。
- 按官网分类、部门、下属单位及栏目组织订阅。保留无链接单位，区分同名栏目，排除页头菜单干扰，合并官网桌面和手机目录的重复项。
- 支持先订阅整个部门，后续接入的栏目自动纳入；也可以逐个选择栏目，刷新进度不覆盖尚未保存的选择。
- 栏目接入独立推进，常见结构直接解析，可选 AI 处理特殊页面。AI 返回经过固定格式解析和实际页面提取后才可使用；单页失败不阻塞其他栏目。
- 暂停和继续覆盖部门发现、栏目接入与导航任务，保留进度及已完成的 AI 结果；主动重试会重新获取未接入页面。
- 改善通知正文与图片显示、加载反馈、AI 配置、用量统计及访问失败提示。

升级保留已有订阅、通知、收藏与阅读记录。源码与安装版默认使用同一桌面数据位置；旧源码项目的 `data/` 不会自动移动，可用 `python app.py --data-dir "原数据目录"` 继续使用。历史数据库中的内部归属记录保留用于兼容，不再提供账号功能。0.2.0 不再提供多人网站部署入口。

Windows x64 提供安装程序和便携 ZIP；Apple 芯片与 Intel Mac 分别提供 DMG，macOS 15 及以上。首次启动优先使用 Edge／Chrome，缺少时下载独立采集组件。安装包不含开发者数据和凭据。

部门目录样本与自动化测试通过不代表所有学校栏目都已覆盖。AI 服务需自行配置；本版未配置 Windows 商业代码签名或 Apple Developer ID 公证。此前安装过误编号 0.2.x 的用户，请手动下载并覆盖安装一次。
