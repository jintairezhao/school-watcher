School Watcher 2.6：来源发现与修复保存进度，已接通的来源持续采集。

- 使用专用来源 Agent，根据真实官网页面、导航上下文和试抓反馈识别部门、栏目与入口；成功的地址、提取规则和验证记录保存在本机复用。普通新增通知不重新识别整站。
- 通知继续归入收件箱现有左侧“学校→部门→栏目”，移除独立渠道页面。归属不明确时保留真实网站与栏目名称，由后台继续处理，不要求用户逐项核实事实。
- 列表和正文或附件由程序实际验证，识别串栏、文章标题误作栏目名、附件下载页误作发布栏目等情况后拒绝安装新规则。修复通过验证后再替换，保留来源身份、订阅、已读、收藏和历史通知。
- 发现入口持久排队，按小批次继续；取消固定全校页数和入口数截断。网络故障延后重试，预算耗尽显示“额度已用完，进度已保存”，已接通来源继续更新。
- 发现、接入和修复共用同校同轮账本，试验默认上限为 40 次实际模型请求或 200,000 token；缓存不重复计费，重启和内部续跑不重置额度，结果未知的付费请求不自动重发。用户已有费用限制优先。
- 改善真实正文、表格、图片及 PDF 附件材料的读取和反馈；修复正文被栏目检查误拒绝、主正文位于 aside 时被误删、双语栏目名称被截断等问题。附件文件名不足以确认完整身份时明确记录为有限验证。

实测采用已配置的 deepseek-flash 和真实官网，详情见 deploy/SOURCE_AGENT_ACCEPTANCE.md。参考来源数量与实际接通数量分别报告；不同高校的发现效率仍有差异，访问限制和预算用尽可能留下未完成入口。本版本不承诺完整覆盖高校全部来源，未实测参数仍作为试验起点。

升级保留已有订阅、通知与个人状态。本轮不加入本地大模型、通用浏览器 Agent、多 Agent 框架或云端共享来源平台。Windows x64 安装包以约 100 MB 为软目标，各平台实际体积单独记录。首次启动优先使用已安装的 Edge／Chrome，缺少时按需下载采集组件，安装包不捆绑完整浏览器或开发者数据。

Windows x64 提供安装程序和便携 ZIP；Apple 芯片与 Intel Mac 分别提供 DMG，macOS 15 及以上。AI 服务需自行配置；验证码、访问拒绝或尚不支持的动态页面可能暂时无法读取。Windows 商业代码签名和 Apple Developer ID 公证尚未配置。
