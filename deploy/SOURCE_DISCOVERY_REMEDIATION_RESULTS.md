# 官网结构探索与信源接入：首批实施结果

日期：2026-10-15。对应[整改计划](SOURCE_DISCOVERY_REMEDIATION_PLAN.md)。这是首批代码和受控对照结果，**未完成五校真实接入验收，尚未发布**。

## 已落地

- 既有 `valuable` 探索队列默认使用本科生、研究生、教师的共同需求，允许明确配置覆盖。九类需求用于排序，不创建学校／部门事实、不排除低优先级来源。
- 在首页主干目录的已有优先基础上，增加按实际探索范围 × 需求类别的覆盖偏好。成功读取与验证接通分别记录，动态未完整材料不算成功探测。
- 新 AI 导航任务先识别首页主干和目录正文成员的读取机会，重复全站菜单后排。全部候选保留；批次顺序持久保存，旧任务游标及已付费输入不重新排序。
- 只读复用两条既有安装流程的验证记录，核对配置、真实区域和原始 HTML 哈希。路径信用只沿当前真实链接传播，不向兄弟院系借信用，不按通知篇数奖励。
- 保存选择原因；实际模型执行增加学校轮次、页面和任务关联。实际 usage、预留、未知结果及无法归属分开，尚未据此训练或启用 token 收益率排序。
- 正文抓取、正文布局、文章日期／附件提取以及来源安装器均未修改。接入仍调用原有验证和抽检，稳定来源编号、订阅、已读及收藏保持原流程。

## 失败分析与修复

1. **目录成员被重复导航挤后**：只把首页主干提前仍不足。依据当前解析节点的精确 URL 与定位，将目录正文成员的探索机会提前；角色与部门归属仍由现有 AI／程序证据验证。
2. **新批次可能覆盖旧未知付费子集**：仅保持 DOM 顺序不能防止批量改变后的重叠。新增独立等待身份，按完整实际执行 ID 保护，覆盖上下文变化、恢复别名及记录缺失；明确结算才释放，等待身份不再当作新派发计划。
3. **Crawl4AI 短中文导航误判**：原生引擎把四个正常短中文结构页面标作 `minimal_text` 反爬失败。诊断适配器保留原生失败，只对这一精确启发式结合 HTTP、指定区域和实际 DOM 重新判断；验证码、403、空白 200、缺少目标区域及其他引擎错误不放宽。404 保持失败。
4. **隔离路径与状态口径**：独立环境最终正确设置 `CRAWL4_AI_BASE_DIRECTORY`；早期未满足该隔离条件的诊断保留，但不计为最终隔离通过证据。

## Crawl4AI 当前决定

保留可复验的诊断适配器和对照脚本，默认产品引擎、依赖和正文链路均未替换。普通结构页面两引擎最终得到相同 DOM／入口，尚无真实复杂高校同预算接通效果支持整体替换。

生产替换仍须接上既有共享限速、浏览器生命周期和总时限，并完成真实官网、资源与冻结打包对照。当前隔离环境 97 项发行依赖，`site-packages` 为 694,296,822 字节／694.297 MB／662.133 MiB，**不是 setup.exe 体积**，未默认捆绑到发行版。
