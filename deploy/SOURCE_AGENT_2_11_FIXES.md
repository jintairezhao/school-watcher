# 2.11 官网目录与栏目分页修正

沿用专用来源 Agent、持续采集和本地规则复用。本次用真实浙江大学网页复现导航解析中断，并继续检查相邻栏目分页误用。未重置学校费用或改写用户数据；没有增加浏览器框架、本地模型或独立渠道页面。

## 原因与修复

网页目录可来自普通链接、脚本中的字面数据或没有链接的表格文字。程序用 `DOM定位::text(条目位置)` 保留证据身份，却在导航识别时将整个字符串当成 CSS，导致 `Pseudo-element found` 异常。现在导航和参考目录核对共用 DOM 定位解析，完整证据标识仍保留。

脚本菜单进一步提供实际条目、父级路径、相邻入口和下级条目。材料由已有安全字面量解析器读取，名称及地址必须与原条目对应；不执行网页代码，不跳过这类入口。延后放在页尾声明的菜单也不能因为脚本所在位置而当成页脚工具链接删除。

同一份完整浙江首页材料：修前稳定中断，修后原 99 个链接及标识不变，得到 89 个合法候选，全部有对应目录上下文。这个重放没有新增网络或模型请求；89 是候选数，不是接通来源数。

分页原先从整页选择“下一页”，使没有分页的侧栏误读主栏后续页，再以“内容重复”拒绝侧栏。现在发现、接入、修复和日常采集共用实际列表及栏目边界；列表范围是必填参数，漏传或空值立即拒绝，不允许静默退回整页。同页列表、卡片和不同标题样式分别处理，无法确认范围时明确保留问题。真实列表旁边的兄弟分页控件仍可读取。后续页写通知前重新核对栏目身份；旧进度里未经新边界验证的页码回到当前入口读取，保留来源与用户历史。

真实浙江“信息公开制度”侧栏有 2 条、没有自己的分页。修前误取“最新通知”的 list2，修后不读取该页；主栏实际 16→2 条的分页仍通过，故意重复的真实主栏页仍拒绝。原已接入主栏在内存副本沿保存材料复验，检查 18 条、新增 0，原 3 个来源、36 条内容和发布关系保持；这是配置复用验证，不是新实时更新。侧栏原验证尚未进入正文抽检，不能凭分页修正宣称新接通。

旧分页误判仅针对已记录的 `pagination_repeats_first_page` 复验原规则，保留任务 generation、已付费决策与原额度。其他失败、用户暂停、网站等待和未知付费结果继续保留；复验失败不买新的模型决策。旧治理提案必须通过当前校验才能安装，已激活的正常来源继续复用。

另一个共用问题是日期前缀过度清理。真实链接同时包裹“06-15”“2026”和“2026年本科生招生专业目录”，旧正则把题名中的年份一并删除。现在只清理一段有效日期，保留年份、学年范围及届／级；同一完整列表 14 条重放原文地址不变，目标标题恢复真实年份。原测量数据库中的旧标题不改写，治理提取与日常引擎的实际文本输入分别对照；未新增网络或模型请求。

## 实际恢复与费用

模型仍使用已配置的 deepseek-flash。实际用户配置当时因连续连接失败暂停；旧“测试成功”字段不能覆盖该状态。无认证 DNS、TCP、TLS 和 HEAD 先确认当前官方服务可达，再执行一次标准连接诊断，取得已知 usage 54 token。原未知结果未重发、未释放预留；诊断成功仅用于此次隔离恢复，未修改用户库中的暂停或账单。

浙江原测试尚未发生模型消耗。本次保留同一数据库、报告、任务 `discover:1` 与 generation 2，诊断及普通请求共用原 40 次／200,000 token 上限。已验证诊断只复用一次；切换修复候选后没有再发诊断。真实 API 候选以发布的 2.10 为基线，只冻结 4 个后端和 2 个测试文件，实测快照 SHA-256 为 `7b678e5d8486605526116f0bf17fa8e1b1ce96350ad2bb608c4f0183ec258eb0`。后续分页修正另用保留的真实材料及受控回归验证，未把此前 API 结果标为最终代码的新实测。

两条硕士／博士栏目规则被拒绝的具体原因已重放：名称和 14 条列表实际存在，但 AI 选择的列表容器不包含它选择的面包屑标题。明确反馈后模型仍返回原错误，故拒绝符合现有契约。仅改成已观察到的真实共同祖先，范围检查通过且 14 条记录不变，虚构相邻名称仍拒绝。这是未安装的局部对照，没有完成正文及分页验证，不能计作接通，也没有额外询问模型。

首个来源为“招生宣传片”：6 条列表标签、原文地址和发布关系逐条对应，保存的 3 个浏览器页面标题身份匹配；正文为视频兼容提示，观察到 mp4 地址但未下载。实际两页共有 10 条，本次只收录 6 条，不能称完整分页覆盖。网站与页脚提供本科生招生办公室证据，数据库尚未写入部门关系，没有编造归属。两次保留材料入库重放新增均为 0，不冒充新的实时持续更新。

其余两个来源是“最新公告”14 条和“最新通知”16 条。“最新通知”这个真实栏目保存的是 2008—2016 年的历史列表，不能把栏目名称中的“最新”或这 16 条内容当成近期更新。“最新公告”其中一条原题为“2026年本科生招生专业目录”，原实测保存标题丢失了年份，需与原题对应情况分别记录。三个来源都未写入部门归属；第三栏页脚的“宣传部维护”不等于发布部门。

## 其他学校与回归

当前 2.10 冻结代码还对华中科大、武汉大学、重庆大学、南开大学、山东大学已有真实材料做零新请求复验：36 条原规则通过 34，武汉两条已知错误命名继续拒绝。349 条发布关系中，337 条按原规则对应真实区域、标题及 URL；另不使用标题选择器核对实际链接标签，有 255 条关系／242 个不同通知满足对应条件。正文试抓 107 条，93 条身份匹配；34 条规则中 28 条完整、6 条有限验证。这个材料重放不能代替当前版本重新进行五校同预算实时对照。

链接整卡包含日期／发布者时，朴素标签比较不相等不直接判为文章矛盾；南开 9 个保存标题含列表日期，不能宣称纯文章题目精确。实际部门归属与存储的 group_name 分开核对。真实空栏目、同名部门、完整参考覆盖及长期定时更新仍未完成，原独立样本身份不重新包装。

导航、分页、旧规则恢复和标题清理的定向检查均通过，并保留修前失败记录。最终代码完整隔离回归运行 1,436 项，1,412 通过、24 项按环境跳过、无失败或错误，205.605 秒；被测源文件前后哈希不变，无真实模型或官网请求。平台浏览器、PostgreSQL、安装和升级由发布 CI 单独验收。
