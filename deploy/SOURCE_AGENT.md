# 官网来源 Agent

用户关注高校后，程序保存待处理入口，AI 根据真实页面和进入路径识别部门、栏目与采集规则。程序实际验证列表、正文或附件及存在的后续分页；通过后立即安装来源。持续采集复用已安装配置，导航变化和明确的规则异常才启动对应范围的发现或修复。

通知仍在收件箱左侧按学校、实际发布部门与栏目整理。归属不明确时保留官网名称和路径，由后台继续处理；学生价值只影响排序与筛选。旧 `/channels` 地址兼容跳转到现有来源侧栏，不再提供独立渠道页面。

## 参数与计量

运行值集中在 `backend/services/discovery_policy.py`。下表是试验起点，不是对所有高校的完成率承诺。已保存的用户设置优先；跨进程运行时使用同一应用数据库计数。`WATCHER_DISCOVERY_POLICY` 可向网页、工作进程和浏览器服务传递同一组显式配置。

| 参数 | 起始值 |
| --- | --- |
| 官网全局 / 同主机 / 浏览器并发 | 2 / 1 / 1 |
| 同主机请求启动间隔 | 至少 1 秒，遵守网站更长等待要求 |
| AI 全局 / 同校并发 | 2 / 1 |
| HTTP 连接 / 空闲读取 / 整次读取 | 6 / 16 / 45 秒，分别实现 |
| 浏览器整次读取 | 45 秒；90 秒方案需单独对照验证 |
| 单个 HTML 上限 | 3 MiB，超限明确失败，不使用静默截断材料 |
| 调度切片 / 导航候选批量 | 3 页 / 8 个，余项持久排队 |
| 单次网页证据 | 24 KiB UTF-8，按实际 DOM 区域拆分并保存定位 |
| 普通输出 / 复杂修复输出配置上界 | 当前请求最多 4,096 token；8,192 是保留的待验证配置项，尚未启用，且不得超出已验证模型配置 |
| temperature | 支持时 0.1，不作为正确性保证 |
| 每次决策补读 | 最多 3 个实际观察到的相关合法地址 |
| 分支进展检查 | 每 4 次实际决策检查，连续 2 次无程序确认的新进展停止该分支 |
| 同校同轮费用上限 | 40 次实际模型请求或 200,000 token，任一达到暂停 |
| 普通网络尝试 | 共 3 次；30 / 120 秒延后，错峰 ±20% |
| 重试用尽后的恢复 | 默认 6 小时；不是未探索入口的排队间隔 |
| 日常采集周期 | 30 分钟，来源间错峰 ±10%，尊重用户现有设置 |
| 正文验证 | 默认 3 条，失败时最多 5 条，通常至少 2 条身份匹配 |

预算由发现、接入和修复共享。服务商 usage 是实际 token；为未知结果或执行中请求保留的额度单独显示。缓存复用不计新请求。重启、队列切片和内部续跑不重新发放预算，结果未知的付费请求不自动重发。只有上一轮确实完成、且后续观察到相关结构变化，才允许开启下一轮；未完成工作不能用新轮次绕过上限。

额度不足时显示“额度已用完，进度已保存”，保留待办，已接入来源仍持续更新。用户显式调整额度后可继续同一份进度和用量账本。

## 验证与修复

- 接入同时检查列表区域、可见真实名称、原文地址、来源路径和通知身份。两篇匹配正文只是验证条件之一。邻近栏目串入、名称拼接或身份矛盾会拒绝安装当前规则。
- 只有一条通知可以有限验证并保存依据；空栏目保留为暂无内容。附件和图片型通知不因正文短而排除。分页检查仅针对实际存在的后续页。
- 规则修复先验证再替换，保持稳定来源身份、订阅、已读、收藏与历史。相同名称或相同页面不能单独证明两个来源相同；同一通知的实际刊载来源分别保存。
- 没有新通知不等于规则失效，网络超时也不会直接触发 AI 重写规则。网络、访问限制、材料不完整、提取错误和空栏目分别记录。
- 页面文本始终是证据数据。AI 只能选择已观察到或验证过跳转的地址，不能通过网页指令扩大任务或执行任意代码。

## 实测口径

`tests/acceptance/source_agent_sites.json` 预先划分开发学校和独立验证学校。`scripts/checks/acceptance_source_agent.py` 使用独立数据库、只读已配置模型密钥、真实工作队列和真实 API；报告及原始材料保存在 `.local/agent-validation/`，不发布凭据和用户数据库。

每次对照需要固定代码版本，保存同校同轮账本。测量窗口结束只是本次观察结束，不是生产探索页数上限。模型返回、来源规则接通、通知归属核对是不同指标，不互相替代。

HTTP 传输尝试不能直接当成官网收到的请求：报告区分确定未发送的代理连接失败、已收到响应与发送结果未知；浏览器导航单独计数，未声称记录每个浏览器资源请求。旧版只有逻辑读取计数的结果不与新增传输计数直接比较。缓存命中也分别标明任务读取缓存和发现材料复用。

参数实测状态、实际学校结果和未覆盖条件在本轮验收报告中列出。复杂模型、推理模式和 90 秒浏览器实验必须有真实失败材料支持；不能统一扩大额度或以模拟结果填补官网验收缺项。

## 桌面包

Windows x64 setup.exe 以约 100 MB 为软目标，构建输出 `ASSET_SIZES.json`，逐个报告字节数、十进制 MB 和二进制 MiB。便携包与 macOS 分别记录。安装体积与远程模型判断能力分别评估；本轮不加入本地大模型、通用浏览器 Agent 或多 Agent 框架。
