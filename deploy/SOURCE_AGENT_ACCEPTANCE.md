# 来源 Agent 实测记录（2.6，2026-10-11）

本轮完成专用来源 Agent、持续采集和本地配置复用的实现与实测。**验收仍有缺项；尚不能认定这组参数适用于所有高校，也不能认定全校来源发现效果已经达标。** 已接通来源可用，未完成入口保留。没有统一增加预算或自动更换服务商。

## 样本与版本

真实 API 使用用户已配置并测试通过的 deepseek-flash。各校同一探索轮共用最多 40 次实际请求／200,000 token；用户没有另设更低限额。真实测量使用隔离数据库，只读读取本机配置，未公开密钥或用户数据库。

公开参考材料见 `tests/acceptance/source_agent_oracle.json`：**8 所学校、55 个确认来源、162 条逐栏目核对记录、157 个不同原文地址**。这是人工核对的官网参考集，**不是 Agent 自动接通的数量**。涵盖普通 HTML、多层导航、动态导航、同页多个栏目、正文和附件；真实空栏目、同名不同部门的完整接入对照尚未完成。

旧版为 main 的 `be25dfa1f45cd0cc3a5ebb890eb4e789c269a1b7`。候选每轮保存不可覆盖的代码快照。最终发现与采集测量版本为 v14，797 个文件的 SHA-256 为 `53abcf47835a7375c2f53f3e6363dd561de7e07f82d87ca5aac0add27d17ea4f`；南开大学和山东大学在冻结之后按原费用上限进行独立对照，之后不根据它们的结果调整本轮 AI、发现、采集、规则验证和预算程序。随后实际侧栏核对另发现投影未消费已保存发布方证据，界面投影作针对性修复并重新回归；不能把这部分称为未经样本影响的独立验证。公开回归记录包含最终程序文件哈希。历史 v11 及更早的数据不冒充最终实现的效果。

最终交付版本 v15 的 802 文件快照 SHA-256 为 `24df88c7b868a9d8bd1d11602430d7ae14a4697ddf175b711f026fb6c3c5b738`。与 v14 比较，生产运行文件仅 `backend/services/inbox.py` 改变，用于补齐左侧发布方层；上述 AI、发现、采集、规则验证和预算文件逐个哈希相同。新增真实来源投影 fixture 和针对检查。完整回归及左侧后验使用 v15，真实模型采集数据仍标明 v14，未重开轮次或额外付费。

浙江大学、中科大、北大和武汉大学曾提供修复依据，已经转为回归样本。西安交大和重庆大学原为 v11 独立测量；西安交大结果随后用于修复页面网络恢复，现转为回归样本。最终独立样本另选南开大学和山东大学；不能继续把西安交大算作最终独立样本。南大使用较早候选 v7；不把它冒充最终实现的独立效果。所有历史费用账本保留，武汉大学续跑沿用原账本，未另发额度。

逐窗口耗时、读取、缓存、任务状态、验证错误见 `tests/acceptance/source_agent_measured_results.json`。例如西安交大候选观察 600.515 秒、141 次 HTTP 传输尝试、149 次逻辑读取、26 次任务材料命中；重庆大学为 599.819 秒、138／137／74。发现快照读取计数分别为 1,145／4,625，属于材料查询次数，**不是避免网络请求的比例**。浏览器导航另外记录，未测量全部浏览器子资源。

最终两个独立样本均共享原定 40 次／200,000 token 上限；旧版在各自窗口内未达到上限，新版均在 40 次请求处暂停新增模型请求，已有来源和待处理入口保留。南开旧版／新版观察时间为 747.067／623.795 秒，山东为 610.058／604.079 秒；旧版单次任务可能越过窗口截止时间，不能将这些差异解释为同覆盖率的速度提升。南开新版的 24 条通知逐条核对属于各自真实栏目，3 条规则另对正文或实际附件响应验证。9 条招生 PDF 列表标题含官网同一行的日期，并非精确的纯标题；PDF 响应已真实读取，但独立检查未保留文件字节重新核对内部标题，该部分明确记为有限证据。招生动态和研究生招生等未接通区域及原因也保留。最终两校的人工定位、提取规则重放、原文对应和遗漏明细见 `tests/acceptance/source_agent_final_holdout_checks.json`；这些局部接通结果不代表全校来源全部发现。

两校最终 10 个安装来源、78 条保存发布记录均对应其真实 DOM 栏目，规则范围重放未见邻近栏目串入或虚构名称。山东“学子 风采”“政策 法规”分别来自研究生院主页两个明确区域；原文标签造成名称空格，没有拼接相邻栏目。个别抽检原文虽然实际返回 200 且手工确认身份，程序读取结果仍为 `needs_adapter`，报告没有把这些样本记为程序正文提取通过。小样本正确归属不能推导普遍零错误，也不能代替已知来源覆盖率及未完成条件的验收。

逐个参考来源的接通对应和遗漏原因见 `tests/acceptance/source_agent_reference_comparison.json`。参考集偏重院系栏目，而探索首先接通的多是学校新闻和招生站，因此不能拿保存来源总数替代参考集覆盖。两版本均接通并对应重庆大学通知公告的 3 篇参考原文；其余参考栏目在这些窗口内缺少足够对应记录。西安交大另保留两条招生栏目的真实标题、路径与访问失败依据；补读四篇 HTTP 原文均断开连接，没有伪造正文或把它算成验证通过。

## 已复现问题与修复证据

上述上海交大、西安交大的“0 来源／0 通知”是原定整校测量窗口的结果，保留原记录。下面的恢复验证发生在该窗口之后，复用已经支付的模型结果与检查点，没有新增模型请求，也没有新开探索轮：上海交大原账本仍为 40 次／183,843 token，西安交大仍为 40 次／147,090 token。恢复接通一个已识别来源，不等于重新完成整校 AI 对照验收。公开脱敏恢复记录见 `tests/acceptance/source_agent_recovery_checks.json`；其中实时网络读取与完整保留材料重放分别标注。

- **正文被栏目检查误拒绝**：武汉大学 56 个不同页面、66 组列表标题／正文对应，旧检查把正常文章标作非公开。修正调用上下文后，41 组通过；其余 25 组仍有标题或正文对应问题，未放宽身份要求让它们通过。整个复验不发新 HTTP 或模型请求。
- **文章题目误作栏目名**：武汉大学两条研究生招生首页规则使用置顶文章题目命名。最终代码根据实际标题链接拒绝这两条新规则；日常采集也会转入修复，保留来源 ID 和历史。没有因修复失败删除其他来源。
- **附件页误作栏目**：中科大 17 个实际附件下载页面的保留材料，最终接入预检全部返回非栏目，0 条安装、0 次新模型请求。
- **有效材料被误删**：北大中文系真实正文位于 aside，修复后 3 篇身份和正文对应通过；保留显式导航／侧栏排除条件。双语栏目完整名称保留。5 个实际 PDF 均完整读取并验证文件头、末尾及哈希；数字文件名仍记录有限身份依据，未声称进行了 PDF 语义识别或 OCR。
- **配置可复用**：最终代码对华中科大、武汉大学、重庆大学共 26 条历史安装规则复验，24 条通过、上述 2 条错误命名被拒绝。该项使用保留的完整官网响应，不能替代新的整校 API 测量。
- **发现页面的代理恢复失效**：西安交大招生网 `http://yz.xjtu.edu.cn/` 同址串行对照显示，代理读取断连，直连返回 200。发现队列按持久化页面失败数重试，网络层原先只看父任务失败数，因此后续页面重试没有切换路径。修正衔接后，隔离数据库第一次实际读取失败并保存约 35 秒等待；新进程在等待到期后第二次读取返回 200、完整 HTML 与真实招生网站标题，页面恢复为 fetched，全程 0 次模型请求。仅恢复了该入口读取，未认定全校来源接通。显式要求代理的配置仍不自动直连，不在同一次已发送请求失败后立即重发。汇总证据见 `tests/acceptance/source_agent_network_recovery.json`。
- **上海交大的导航与正文恢复**：原网页以脚本加载导航，正文使用 `Article_content`，旧分类及噪声处理曾使完整、公开正文被误拒绝。已有修复复用了实际脚本导航和正文区域，没有再次重构。恢复后的工作树实时读取通知公告列表、3 条不同正文，逐条验证标题、原文地址与正文后安装 1 个真实来源、采集 10 条通知；随后真实列表再次检查 10 条，新增 0 条、模型调用 0 次。该流程共 5 次普通 HTTP 文档读取及 1 次按需浏览器导航，浏览器子资源未单独计数。另将原付费任务检查点放入隔离数据库、使用完整保留官网材料，自动恢复接通同一栏目，新增 HTTP 与模型请求均为 0；这一项是材料重放，不是实时网络试验。
- **西安交大的代理 403 与已识别来源恢复**：新闻网同一原文首次实际读取由自动环境代理返回 403，正确记录为网络路径问题，保存等待后由新进程直连读取到 200；单页恢复没有调用模型。再使用 v11 原付费检查点中的“交大要闻”规则，按持久化重试、同主机等待及正文缓存复用，实际读通正文、验证列表作用域，安装 1 个来源并采到 8 条通知。其他原模型规则仍有作用域、日期或原文链接错误，未强行安装。公开记录也列出验收脚本一次中断后的额外读取与等待，不能把它隐藏在成功计数中。
- **正文标题的完整与有限证据分开**：最终 v13 使用上述西安交大完整保留响应复验，作用域通过，3 个正文样本中 2 个完整标题匹配；1 个官网首页标题本身带省略号，记录为有限观察，不计作完整标题匹配，验证状态为 limited。此复验为 0 HTTP／0 模型的材料重放。验证器版本仍为 3；恢复实时运行没有记录精确程序文件哈希，不能把这些读取冒充最终 v13 的实时整校结果。最终标题复验记录附有当时的程序文件哈希。
- **访问限制与规则错误分别恢复**：受限、登录或人工验证等访问问题保留来源与进度，不进入付费规则改写；公开可读、身份对应的正文仍可验证。旧检查点恢复优先执行已经完成的模型栏目规则，并纠正遗留 `material_pending` 导致的无效续排，仍须重新执行作用域与正文验证后才能安装。相关 82 项受控回归通过，覆盖访问问题分类、原规则重试、检查点恢复及既有来源验证；其中“访问受限不触发 AI”由测试调用守卫确认。这些是受控测试，不是额外的真实官网或真实 API 验收。
- **重复导航材料复用**：保留页面与原模型输出的重放中，西安交大导航需处理的不同模型批次从 26 个降为 12 个，复用 118 个候选分类；重庆大学仍为 25→25，上海交大仍为 7→7。复用仅适用于实际导航材料、名称、地址和上下文一致的角色判断，不据此合并渠道或编造归属。该项实际 HTTP 与模型请求均为 0，未重新询问模型生成未命中子批次的回答，因此只能证明历史材料上的复用机会，不能宣传为实付费用或 token 已降低。详见 `tests/acceptance/source_agent_navigation_reuse.json`。
- **未知付费请求与缓存变化**：导航批次发出前保存原始材料、候选和决策身份；其他任务新增缓存不能把尚未知结果的已发送请求改成新批次重发。无新检查点的旧请求按原输入摘要恢复。21 项受控导航检查通过，覆盖预算用尽时先保存免费缓存进展、未知结果恢复及旧检查点；未人为发送结果未知的真实付费请求。
- **规则恢复后仍有未读区域**：使用西安交大原付费检查点，最终 v14 在 40 次／147,090 token 的原账本下恢复“交大要闻”并保存 8 条通知；下一条未读区域保留并进入预算等待，没有提前标记任务完成。该项使用完整保留官网材料、实际预算与任务运行路径，新增 HTTP 和模型请求均为 0；公开恢复记录第 7 项附程序哈希和阶段变化。
- **左侧未使用已保存的发布方证据**：v14 的真实两校结果没有单独 unit 记录，左侧旧 fallback 因此只显示学校／其他分组中的栏目叶子。v15 复用已有 `channels_for` 的实际网站标识与稳定发布方 key，补齐可展开发布方层；明确目录关系和原叶子名称优先保留，不增加模型请求，不合并来源 ID。南开显示人事处、本科招生网以及归属未知的信息公开实际地址；山东研究生院同页两栏归在同一发布方下，两个渠道 ID 独立，招生站三栏缺少共同入口证据时保守按地址区分。原始两库中来源、通知、订阅、已读、收藏、验证、任务及账本逻辑哈希未变。实际模板前后核对见 `tests/acceptance/source_agent_sidebar_projection_checks.json`。复制真实隔离结果后使用 Edge 在 1440／390 宽度实际展开和点选过滤通过，新增官网和模型请求均为 0；它是保留材料上的 UI 验证，不是再次整校发现。
- **持续采集与恢复**：隔离复制克拉玛依 3 条真实配置，在新进程中恢复队列后采到 23 条新增通知；下一次实际读取 3 个列表没有新增，0 次模型请求，来源 ID、规则、订阅、已读、收藏和历史保留。初次陈旧任务未采集的结果与后续网络超时也保存。该隔离验证未启用 AI 绑定，不能据此宣称所有已启用 AI 的日常路径都实测零调用；也不是突然断电实验。
