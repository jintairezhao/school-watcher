# 2.9 来源发现修正

本轮复用现有来源 Agent、持久任务和左侧学校→部门→栏目。修正观察材料、动态加载、探索顺序和模型连接恢复，不新增渠道页面、通用浏览器 Agent、云端来源库或本地模型。旧通知日期只提示应继续探查，不能证明网站弃用。

## 实际观察与对照

| 样本 | 修正前的问题 | 本轮核对结果 |
| --- | --- | --- |
| 人大本科招生首页 | HTTP 和 DOMContentLoaded 已有日期和标题，但通知链接仍指向 `/`；局部加载又会提前判完整 | 改后真实 production coordinator→Edge 在 45 秒内取得与先前完整 DOM 一致的 29 个出现项（27 个不同标题／地址），5 个栏目入口补全。首轮补读仍过早完成的失败记录保留，修正后再次验证 |
| 人大研究生招生首页 | 同名标题匹配两个选项卡区域，标题不在模型给出的列表面板内 | 保留 HTML 重放补齐 8 个真实标题及共同局部区域的唯一原始定位；原串栏规则仍被拒绝。这不是 8 个来源的新接通成绩 |
| 山东大学首页 | 把文章小标题当栏目，材料拆成 26 批 | 同一份真实 HTML 改后为 4 批；61 个可确认文章链接全部保留，24 KiB 上限不变。未把材料批数差当成已实测的模型费用降幅 |
| 人大专业设置 | 混合机构目录和真实发布列表的页面被无条件跳过 | 保留材料有两个真实通知地址；有发布证据的混合页进入原列表范围、名称与正文验证，纯机构名录不因此付费 |
| 人大财政金融学院 | 用户指出旧公告与专题内新公告的反常路径 | 本次真实 HTTP 读取首页及用户给出的新公告地址均为 502，保留失败；只完成通用路径行为回归，未宣称该学院自动接通 |

真实动态读取使用隔离运行目录和限速账本，未访问用户数据库、未调用模型；为了诊断，图片／字体／媒体被阻止，因此时长不是所有资源加载下的生产性能基准。完整指标见 [本轮核对记录](../tests/acceptance/source_agent_2_9_checks.json)。

探索排序借鉴[聚焦爬取](https://www.cse.iitb.ac.in/~soumen/doc/www1999f/pdf/www1999f.pdf)：从真实导航开始，以读取反馈调整下一步，并保留陌生入口的探查机会。排序分数是工程启发式，不是校准概率或正确率保证。AI 仍判断真实部门和栏目，程序仍执行列表、正文和归属校验；观察到的近邻关系只影响探查顺序，不能当作部门隶属证据。

7 份人大保留页面已完成探索前后重放，未调用 API 或官网；图片和无标签入口保留真实地址，重复首页仍由库存去重。动态模板壳只用于观察对照，必须先完成渲染，不把壳中的探查候选算作已接通来源。旧付费模型结果按原输入、配置及请求记录恢复，补充标题定位不能清空已完成区域或重新支付；不匹配或结果未知时保留原进度等待。

| 参数 | 当前值 | 状态 |

| HTTP 连接／空闲／总时限；浏览器时限 | 6／16／45 秒；45 秒 | 已实测保留：没有统一延长；90 秒方案尚未验证 |
| HTML／网页证据／普通输出 | 3 MiB／24 KiB／4,096 token | 已实测保留：真实材料完整分批；8,192 输出和更强推理模式尚未验证 |
| 切片／导航批量 | 3 页／8 个 | 已实测保留：保留后续入口；文章小标题不再增加虚假的栏目批数 |
| 探查保底 | 每 5 次官网任务认领保留一次探查机会 | 尚未验证整校最优值；受控持久队列与公平续跑验证，不新增模型调用额度 |
| 模型连接暂停阈值 | 连续 2 次连接故障 | 尚未验证生产最优值；故障、跨进程和成功测试恢复通过隔离验证，结果未知的请求不重发 |
| 同校同轮模型预算 | 40 次实际请求／200,000 token | 已实测保留：已有额度、账本与未知费用预留不重置；本轮没有新增真实模型请求 |
| 日期、新旧和串栏判定 | 日期须来自真实发布内容；旧内容保留 | 实测后调整的是观察、排序与校验反馈；不按年份硬删除来源，不放宽栏目范围和正文身份校验 |

人大原探索轮记录 25 次请求、50,246 个已知实际 token、148,984 个结果未知请求的保守预留 token。模型断连后持续派发、未知结果误计无进展是程序缺陷；未知费用本身不能按响应很快或零字节假定未扣费。新实现保存原付费请求与进度，成功连接测试不会清除未知账或增加学校额度，已接通来源继续采集。

本轮尚未完成调整后同费用预算的整校真实 API 对照，不能据此声称人大从 6 个来源提升至某个数量，亦不能替代原要求的多校／50 来源／100 通知全流程验收。[先前验收与缺项](SOURCE_AGENT_ACCEPTANCE.md)继续有效。安装包实际字节数、MB、MiB 以 2.9 的 CI 和发布资产为准，不沿用旧包；Windows 约 100 MB 仍为软目标。

最终本地隔离回归运行 1,345 项：1,321 项通过、24 项按条件跳过，无失败；未调用真实模型或使用用户应用数据库。测试网络与临时目录配置不当的两次前置尝试记录另行保留，纠正测试环境后重跑全量，不关闭安装目录保护来通过测试。平台构建、浏览器交互及打包运行检查由发布 CI 单独执行。
