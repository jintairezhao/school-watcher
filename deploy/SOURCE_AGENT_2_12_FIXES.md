# 2.12 修复验收

来源路径和左侧来源栏共用已保存的真实名称。未知发布单位不再以网址构造部门层级，同名来源依旧保留独立身份；官网地址保留为链接。这个显示调整不修改来源配置、订阅或用户状态。

发现样本、规则验证和日常采集共用标题字段提取。讲座卡片中的时间、地点、讲者和标签不再拼入标题；合法年份、学年范围和数字仍保留。日常采集重新观察到同一原文时，只修正与当前材料证明的历史错误形式完全匹配的主来源标题，不替换普通旧标题或其他来源的标题，不新增重复通知。

实际取得上海交通大学讲座列表的完整 HTTP 响应（25,137 UTF-8 字节，SHA-256 `91fa0cacff6c17b412f8950f75648ac0cb9e85135787060641c3d880fdf5fc6d`）。该响应的读取结果为 `requires_render`，因此这里仅验证其中已存在的列表 DOM，不将它算作动态页面接通或全校发现成功。

在同一材料上回放当前保存的规则：10 条列表记录通过栏目区域校验，10 条对应的旧错误标题在隔离数据库中修正，新增重复通知为 0。另用 9 个已保存真实来源核对路径与左栏无网址标签、来源身份无损失。原始用户数据库未用于运行或修改；不可变旧记录副本的文件散列前后相同。本轮这些修复没有实际模型请求，官网证据获取为一次 HTTP 读取。

隔离 Edge 检查覆盖桌面和窄屏：通知阅读不再请求用途分析或摘要；历史数据和原有 AI 绑定、费用上限保留；来源设置仍可发现和采集；切换学校、栏目、收藏、页面返回、浏览器前进后退、失败响应及不可用的浏览器存储均有检查。

这些结果用于确认此次已复现问题的修复，不代表全校覆盖率或所有网页结构都已验证。学校探索、采集并发及费用默认值沿用现有配置，本轮未提高额度。尚未重新读到的历史错误标题留待后续采集用真实材料修正。
