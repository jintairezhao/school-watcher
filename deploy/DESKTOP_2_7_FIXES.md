# 2.7 桌面交互与旧来源兼容修复

本次修复用户在实际 2.6 安装版发现的两处程序问题，不重新运行 AI 来源发现，也不以界面验收替代官网采集验收。

## 根因与修复

1. **旧栏目显示成网址单位**：升级保留的上海交大来源没有独立部门记录、目录父子关系或可用的本地发布目录；安装包又排除了完整开发种子文件，而侧栏旧配置显示回退仍依赖该文件。因此既有学院关系没有进入显示投影，每个页面退回“网址→1 个栏目”。本次加入显示专用兼容材料。学校地址、来源名称、原分组、来源地址及列表区域哈希必须全部匹配，已有本地官网证据优先；没有匹配时继续保留未知状态，不根据域名或名称猜归属。来源 ID 与提取规则不变，不安装旧学校或来源。
2. **添加、编辑学校点击报错**：按钮函数访问 schoolModal、modalTitle 等节点，但对应弹窗 DOM 已从模板删除。实际 Edge 复现 Cannot set properties of null (setting 'textContent')。恢复共用原生 dialog，沿用原保存接口和 CSRF，支持取消、Esc、输入校验、焦点返回与失败提示。

## 实际验证范围

- 读取正在使用的数据目录时仅通过 SQLite 只读连接取得现有来源元数据，并制作包含已提交 WAL 的私密副本。没有修改用户原库、输出密钥或提交用户数据库。
- 无完整开发种子、无本地上海交大发布目录的实际资源打包形态先复现失败，再验证通过。截图对应心理学院 4 条、物理与天文学院 2 条真实既有来源，严格配置匹配后恢复为“院系设置→学院→栏目”。
- 真实用户数据的隔离副本使用 Edge，在 1440／390 宽度实际展开和点击筛选；六条来源没有网址假单位，按原渠道 ID 筛选后，服务端返回的通知仍有相应实际发布来源关系。所有外部网络、模型调用及数据库写入受阻断，基准副本和界面副本的 17 张保护表逻辑哈希均未变。截图仅在本机私密工作目录保存。
- 学校弹窗使用隔离数据，在 1280 深色／390 浅色实际点击。添加和编辑字段、取消、Esc、焦点、POST／PUT 数据、后端失败提示、成功关闭及再次添加时清空编辑 ID 均通过。保存请求由浏览器拦截验证，未把模拟保存响应当成真实学校接入成功。
- 74 项显示兼容、目录身份和渠道投影针对性回归通过；87 项桌面回归通过。两组有重叠，不相加宣称独立测试数量。新增学校弹窗浏览器验收纳入 Windows 发布流水线。

兼容材料为 121,956 字节，199 条已公开旧来源的显示路径；没有正文提取规则、API 配置或自动安装名单。其作用仅是恢复已保存且身份完全匹配的旧配置显示，不构成新发现或采集成绩。
