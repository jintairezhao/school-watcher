# 实例 AI 配置

线上管理员和本地部署者使用相同的管理设置。普通用户没有独立 API 密钥入口。分别指定目录和摘要的服务配置，可使用 DeepSeek、阿里云百炼、火山方舟或智谱官方接口。

新增或修改模型、地域、密钥后，需要管理员主动执行连接测试；测试会产生一次小额度请求并记录用量。通过结构化输出和用量检查后才能绑定用途。密钥变更不重生成旧摘要。接口失败不自动换服务商。

本地启动自动在当前应用数据目录生成 `.field-key`，只供本实例解密凭据，切勿提交到 Git 或分享。完整数据备份不包含该主密钥；迁移实例时通过独立安全通道保存它，或恢复后重新配置 API。已有 FIELD_ENC_KEY 环境变量优先。本地多个进程共享同一数据目录与主密钥。

Linux 生产环境必须设置 FIELD_ENC_KEY，Compose 已声明该必需变量。不要更换正在使用的主密钥，否则既有密文不可读。生产部署未设置主密钥时启动失败，不退回明文。Windows 文件权限继承应用数据目录的账户权限，应将数据目录放在只有部署者可以访问的位置。

管理页面的月度额度单位是 token，0 表示不设消费上限；分别统计总额、目录和摘要。请求发出前按保守输入规模和最大输出预留，完成后按服务商实际用量结算。未知用量保留预留记录，供应商账单为准。并发数默认 2，与消费额度独立。

意外退出或备份恢复中的付费请求标为结果待核实，不自动重放。调用账本用于排查和手工用量核对，不能把数据库中的请求标识当作供应商幂等性保证。

新 Skill 和适配器经过离线模拟测试；各服务商的真实模型仍需管理员在当前部署主动测试。未进行真实调用或未跑 PostgreSQL/全名单验收时，不宣称这些验收已通过。
