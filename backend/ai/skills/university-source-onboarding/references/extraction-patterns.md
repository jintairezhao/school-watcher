# 可复用的网页经验
WebPlus 常有 wp_list、wp_articlecontent；VSB 常有 v_news_content；WordPress 常有 article.type-post、category 和 single。它们是候选规则，必须在当前完整 DOM 上验证；绝不因模板名匹配就通过。
列表规则定位每一条记录，标题/链接/日期相对于记录定位。避免选择整个 ul 后只取首条，也避免把同页邻栏合入。导航标题、轮播重复项、返回按钮不是通知。正文选择器只能依据已取得的正文页填写。
日期可能是 YYYY-MM-DD、YYYY年M月D日、分开的年/月/日、time[datetime] 或无日期。缺失日期留空，不从抓取日期猜发布日期。分页请求必须使用实际观察到的下一页 URL；下一页重复首页须停止，不能不断递增猜路径。
缺少正文时请求列表实际链接，登录条目可再读其他公开条目，记录限制；所有样本均需登录则无法完成公开正文验证。独立复核由程序单独读取，不能把同一缓存副本称为独立核实。
