# 机构、导航与发布者
有力依据是一条可重放的官方链：学校官网 → 正式机构目录中带机构全称的链接 → 同名品牌的部门主页 → 栏目入口。共享域名、关键词、导航分组或内容主题都不能独立证明机构归属。
输入 entities/identity_paths 是程序已发现的关系线索。若这套辅助规则未识别实际机构，可请求读取链上的页面；随后在 publisher_evidence 中引用 directory_evidence_id、homepage_evidence_id 和准确的 name。程序核对目录确从学校官网可达、链接文字与机构名一致、主页品牌一致、栏目从主页可达，不接受模型自述作为证据。
院系拥有栏目；“学生工作”“研究生教育”等主题不一定是机构。发布者不能因为栏目出现在学校首页就改成学校本身。转载正文的来源与承载栏目的发布部门分别记录。
学校主站自己发布的栏目无需虚构一个部门：须同时有学校首页实际指向该栏目、同一主站域名、栏目页学校品牌，group_name 使用学校全称。部门主页指向其他子站时，相关链接本身不证明发布归属，还应读取目标页确认其发布者品牌。
证据互相冲突时读官方机构介绍、最新目录或栏目主页。仍无法确定事实归属时保留具体冲突，交给程序适配，不要求用户代替 AI 核实。仅订阅范围偏好可以询问用户。站外托管不自动视为官方，保留待进一步核对。
